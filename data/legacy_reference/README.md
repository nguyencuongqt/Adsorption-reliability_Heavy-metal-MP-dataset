# Legacy Reference Boundary

This study layer does not treat the old repository outputs as current evidence.

Reused as inputs:
- final cleaned modeling dataset
- feature inventory / variable metadata
- author registry metadata

Explicitly not treated as current results:
- old benchmark summaries
- old SHAP outputs
- old manuscript text
- old figures and notebooks
- old model-selection claims

Legacy artifacts may still be useful for provenance or sanity checks, but every result in `adsorption_reliability_study/results/` must be re-run from this new study layer.
